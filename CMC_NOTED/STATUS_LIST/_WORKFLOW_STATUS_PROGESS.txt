✅ Key Notes:

Pending → Accepted/Rejected

Only client can approve or reject.

Accepted → In Progress

Project starts execution workflow.

Execution Stages:

Planning → Foundation → Structural → Electrical/Plumbing → Interior → Landscaping → Testing → Completed

Exceptions:

Delayed: If project faces issues at any stage.

Cancelled: If project is terminated mid-way.

Frontend Usage:

Use STATUS_NAME and STATUS_BG_CLASS for badges.

Use STATUS_ICON for visual cues.

Status updates should follow this flow.
