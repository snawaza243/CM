✅ Usage Notes:

Table Source: CM_PROGRESS_STATUS

STATUS_NAME → display name of the status

STATUS_DESC → detailed description for tooltips or info panels

STATUS_BG_CLASS → Bootstrap badge or custom CSS for visual representation

Front-End Display:

<span class="badge {{STATUS_BG_CLASS}}">{{STATUS_NAME}}</span>


Replace {{STATUS_BG_CLASS}} and {{STATUS_NAME}} dynamically from your database.

Color Guidance:

Use default Bootstrap classes where possible (bg-primary, bg-success, etc.).

For custom colors (like purple or orange), define in your CSS:

.bg-purple { background-color: #6f42c1; color: #fff; }
.bg-orange { background-color: #fd7e14; color: #fff; }


Database Mapping:

STATUS_ACTIVE = 'Y' → active status, show in dropdowns or UI

STATUS_TYPE → optional grouping (Planning, Structural, Finishing, Quality, Issue)

Recommended Front-End Use:

Table / Dashboard: show all projects with status badges

Modal / Detail View: show STATUS_DESC for more information

Color Coding: use STATUS_BG_CLASS to visually indicate progress
